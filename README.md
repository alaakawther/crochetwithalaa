# 🧶 Crochet With Alaa

A terminal-based Python program that helps crochet beginners learn to crochet, discover projects to make, and look up quick crochet reference info.

## Tech Stack

- **Language:** Python 3
- **Interface:** Terminal / Command Prompt
- **Storage:** JSON (for saved custom tutorials)
- **Version control:** Git + GitHub

## Run it

```bash
python main.py
```

## Features

- **Learn Crochet** — a guided path across 4 experience levels, from "I know nothing" to "I've made big projects"
- **Crochet Patterns** — 18 projects (12 beginner, 6 advanced), each linked to a YouTube tutorial and their will be more on the way
- **Crochet Tools** — a reference section on yarn, hooks, gauge, tension, abbreviations, and common mistakes
- **Custom Tutorials** — write your own tutorial and save it permanently to `data/tutorials.json`

## Project Structure

```
crochetwithalaa/
├── main.py      entry point
├── data/        project + crochet reference data, saved tutorials
├── menus/       menu screens and routing
├── features/    the functionality behind each menu
├── utils/       shared display + input helpers
```
